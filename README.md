CueLine 是一台做播客和电台节目的桌面工作台。一集节目从原稿开始，经过口播稿、声音、剪辑，最后导出成片，五个工位都在一个窗口里。资料库存在你自己的电脑上。

> 现在是**测试版**：功能还在补，界面和数据格式可能会变。遇到问题请在这个仓库 [提 Issue](https://github.com/tulai-design/cueline-releases/issues)。

## 五个工位

| 工位 | 做什么 |
| --- | --- |
| **原稿** | 你自己写文章，支持插图、标题、列表。AI 只读不写：提炼要点和大纲，点一下跳回原文那一段。可以导出 Markdown |
| **口播稿** | 按发言人分段，插停顿、吸气、演绎提示，给几个字加放慢、重读、耳语。AI 可以把原稿改成口播稿（长短、氛围、口语程度、标记多少都能选），也可以改写一段、选中的几句或整篇；改完逐字对比，你点「接受」才算数 |
| **声音** | 逐段录；一口气连录；导入一整段录音，按识别出的文字切到每一段；先录后整理，识别后自己对上谁是谁。也可以用 AI 配音，大约 110 种固定音色，选的时候能试听、能看到档位和价格 |
| **剪辑** | 多轨时间线：人声、背景音乐、音效各一条轨。对着文字稿剪，删字就是删音频。拖片段的手感接近 Premiere：直接拖是覆盖，按住 ⌘ 是插入，⌘⌥ 是重排。可以独奏、静音、调音量 |
| **导出** | MP3 或 WAV，响度统一到 -16 LUFS（也可以选 -14、-18 或不调），带标题、节目名、封面标签。另外导出字幕（SRT，按成片时间）、节目简介（带时间戳）和口播稿 |

素材库里还能用 AI 生成背景音乐和音效：背景音乐可以要纯音乐或带人声的歌（自己写词，或者让 AI 按描述写）；音效可以要单次的或者能循环的环境声。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | macOS 13 Ventura 或更新 |
| 芯片 | Apple 芯片（M1 及以后）。Intel Mac 的版本还没有 |
| 网络 | 写稿、录音、剪辑、导出不用联网；AI 功能和登录要联网 |
| 麦克风 | 录音时要用，第一次录音会问你要权限 |
| 空间 | 安装包约 12 MB；录音和素材另算，存在你的资料库里 |

Windows 版还在准备。

## 安装

1. 下载 [CueLine-mac-arm64.dmg](https://github.com/tulai-design/cueline-releases/releases/latest/download/CueLine-mac-arm64.dmg)
2. 双击打开下载好的 dmg，会出现一个小窗口
3. 把 CueLine 拖进「应用程序」
4. 推出 dmg（在访达侧边栏点它旁边的 ⏏），dmg 文件可以删掉了

## 第一次打开

测试版**还没有经过 Apple 的签名和公证**，第一次打开时 macOS 会拦一下。任选一种方法放行，之后就不会再问：

**方法一：右键打开**

1. 打开访达里的「应用程序」
2. 按住 Control 点 CueLine（或者右键）→「打开」
3. 弹出的窗口里再点「打开」

**方法二：在系统设置里允许**

1. 先双击 CueLine，看到「无法打开」的提示后点「好」
2. 打开 系统设置 → 隐私与安全性
3. 往下翻，在「安全性」那里找到 CueLine，点「仍要打开」，输入开机密码

**如果提示「已损坏，无法打开」**

这是 macOS 对从网上下载、没签名的应用加的隔离标记，不是文件真的坏了。打开「终端」，粘贴下面这行回车：

```sh
xattr -dr com.apple.quarantine /Applications/CueLine.app
```

然后再按上面的方法一打开。

## 更新

测试版还没有自动更新。出了新版本：

1. 到 [Releases](https://github.com/tulai-design/cueline-releases/releases) 下载最新的 dmg
2. 退出 CueLine
3. 把新的 CueLine 拖进「应用程序」，选「替换」

资料库不会受影响，原来的稿子、录音、剪辑都还在。替换以后第一次打开可能又要按 [第一次打开](#第一次打开) 放行一次。

想第一时间知道新版本：在这个仓库右上角点 **Watch → Custom → Releases**。

## 账号和积分

- **登录**：邮箱验证码，或者 GitHub。不设密码。不登录也能写稿、录音、剪辑、导出，只有 AI 功能要登录
- **积分**：AI 功能按积分算。按钮旁边会写这次大约多少积分；做完按实际用量扣，**没做成不扣**
- **对齐文字稿**：自己录的声音拿去识别，换成每个字的真实时间。每一集前 1.5 小时免费
- **档位**：AI 改写和提炼有三个档位，越高的档效果越好、积分也越多。配音的档位跟着音色走，选音色时就能看到

积分的余额、明细和兑换码在 app 里的账号面板。

## 你的数据在哪里

所有稿子、录音、剪辑工程都在你自己电脑的 **文稿/CueLine** 文件夹里：

| 位置 | 是什么 |
| --- | --- |
| `文稿/CueLine/` | 资料库：系列、单集、原稿、口播稿、主播、剪辑工程 |
| `文稿/CueLine/media/` | 录音、导入的音频、AI 配的声音、图片，按内容存，同样的文件只存一份 |
| `文稿/CueLine/backups/` | 每天自动备份一次资料库 |

想备份就把整个 `CueLine` 文件夹复制走。换电脑时复制过去，装好 app 打开就是原样（多台电脑之间的自动同步还没做）。

## 隐私

- **稿子、录音和剪辑工程都只在你的电脑上**，不会上传
- 用 AI 功能时，那一次要处理的内容会发给我们的服务器，再交给 AI 服务：
  - 提炼和改写：发的是那几段文字
  - AI 配音：发的是那一段文字
  - 识别和对齐：录音会临时传到云端存储，识别完（成没成都一样）立刻删掉
- 生成的结果传回你的电脑以后，服务器上的那份会清掉
- 我们记录每次 AI 任务用了多少、扣了多少积分，用来对账；不记录你的稿子正文

## 卸载

1. 把「应用程序」里的 CueLine 拖进废纸篓
2. 想连资料一起删：再删掉 `文稿/CueLine`（**删了就找不回来**，先确认不要了）
3. 登录信息存在钥匙串里：打开「钥匙串访问」，搜 `app.cueline.desktop` 删掉

## 常见问题

<details>
<summary><b>录音没有声音 / 电平表不动</b></summary>

打开 系统设置 → 隐私与安全性 → 麦克风，确认 CueLine 是打开的。改了以后要退出 CueLine 再打开。
</details>

<details>
<summary><b>收不到邮箱验证码</b></summary>

先看看垃圾邮件。验证码 10 分钟内有效，可以重新发一次。还是收不到可以用 GitHub 登录，或者提 Issue 告诉我们你的邮箱后缀（比如 @qq.com）。
</details>

<details>
<summary><b>AI 按钮提示「暂时用不了」</b></summary>

是我们这边的服务出了问题，不是你的操作有问题，也不会扣积分。我们会尽快处理，过一会儿再试。
</details>

<details>
<summary><b>导出很慢，界面卡住</b></summary>

测试版的导出在 app 里完成，一小时的节目编码要几十秒，期间界面会卡一下，等它做完就好。两三个小时的长节目可能会占很多内存，以后会改。
</details>

<details>
<summary><b>支持 Intel Mac、Windows 吗</b></summary>

还没有。现在只有 Apple 芯片的 Mac 版，Windows 版在准备。
</details>

<details>
<summary><b>AI 会帮我写原稿吗</b></summary>

不会。原稿是你写的，AI 只读：提炼要点、列大纲。口播稿的改写也要你看过对比、点了「接受」才会写进去。
</details>

## 版本说明

每个版本的改动写在 [Releases](https://github.com/tulai-design/cueline-releases/releases) 里。版本号是 `主.次.修订`；带 `-beta` 这类后缀的是预览版。

每个 Release 里附了安装包的 SHA-256，想核对可以在终端里：

```sh
shasum -a 256 ~/Downloads/CueLine-mac-arm64.dmg
```
